# Banner

`banner-light.svg` and `banner-dark.svg` are generated from `banner.toml` with
[dojo-readme-kit](https://github.com/DojoCodingLabs/.github/tree/main/kit), in the
[dojocoding.io](https://dojocoding.io) visual system. To change the banner, edit `banner.toml` and run:

    uvx --from "git+https://github.com/DojoCodingLabs/.github#subdirectory=kit" dojo-banner docs/assets/banner.toml

`dojocoding-mark.png` is the official Dojo Coding mark, used in the README footer.
